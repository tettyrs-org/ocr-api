TROUBLESHOOTING
================================================================================

404 on /process endpoint:
  → Rebuild: mvn clean compile
  → Restart server

401 Unauthorized:
  → Check Authorization header: "Authorization: Bearer {TOKEN}"

400 Bad Request on document creation:
  → Check field names (snake_case):
    Correct: file_size, mime_type, document_type, created_by
    Wrong: fileSize, mimeType, documentType, createdBy

Unsupported document_type:
  → Use valid enum: "OTHER" (not "GENERAL")

Processing never completes:
  → Check backend services:
    - API on 8081
    - MS-OCR on 8080
    - OCR-Engine on 8000
  → Check logs for errors
  → Verify database connectivity
